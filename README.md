# Josefines Bokregister
Detta är en konsolapplikation som skapats i syfte att kunna lagra information om böcker. Allt som användaren behöver för att få programmet att fungera finns i bifogade filer i repot.
Funktionerna som erbjuds består av följande:
- Lägga till böcker
- Se böcker
- Söka bland böcker efter titel och författare
- Ändra böcker
- Ta bort böcker
- Ändra lässtatus på böcker (oläst, pågående eller utläst)
